# sf-symbols-json

SF Symbols Characters and Keys in JSON format.

This repository contains a JSON representation of the SF Symbols characters and their corresponding keys. It is useful for developers who want to programmatically access SF Symbols data.

## SF Symbols 7

This JSON file is based on SF Symbols version 7. It includes all the symbols available in this version along with their respective keys.
